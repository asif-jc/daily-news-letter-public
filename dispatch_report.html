6. Architecture options and decisions to discuss

My lean: a home-scheduled Python build with durable local state, a configurable local-model client, a validated edition artifact, and a public static bundle deployed to GitHub Pages. SQLite is a reasonable candidate for question/serving history and observations because they need durable queries; it is not a reason to restore the old commented database layer. Keep rendering replayable without network or inference. This is a candidate direction, not a selected design.
