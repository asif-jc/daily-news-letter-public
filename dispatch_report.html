Architecture and decisions

The Dense Discovery reference supplies the warm archive-reader direction. Our Python renderer emits the complete escaped stories once. Plain CSS creates the split reading surface and mobile drawer; a small JavaScript module selects stories, filters the index and maintains explicit browser-local read marks. No frontend framework, backend service, subscription system or recommendation footer was added.

The existing reader whitelist, approved source URLs, revision-aware read identity, seven-day history and dated archives remain the content boundary. Automatic filter selection replaces the URL; selecting a title adds a browser history entry. Archive links preserve the archive pathname. A render checkpoint version change prevents reuse of former HTML.

The top-right Original action opens the first approved source; all sources and available dates remain below the summary. Header text is a reviewed summary sentence or the reviewed title, labelled From this briefing. It is not attributed speech. News prompts, editorial preferences and retained factual summaries are unchanged.

Issue 411 credits Justina Leisyte for its art; no reusable library licence was established. Three original transparent illustrations and an original folded-paper/N logo are included. The art is thematic and reused across topics. Story-specific illustration generation is deliberately not part of this workflow.

Review and delivery

Astra's first requirements review identified two P2 issues: filter selection left stale story URLs, and expanded options lacked an overall sidebar scroll path. Both were corrected and checked in a browser. The second pass found and verified a further Back-navigation edge case after incompatible or empty filters. It is fixed and covered by actual browser history regressions. Astra independently reran both sequences against the current JavaScript and found no remaining material findings. The actual PR review and delivered preview checks remain delivery gates.

Before publication, the exact outgoing files and commits receive fully redacted credential scans and separate checks for private infrastructure, paths, personal data and image metadata. Runtime settings, raw reference captures, source evidence and model outputs remain ignored. A clean scanner alone does not establish privacy.

Accepted limits

Read marks remain browser-local. The three images are topic-level artwork, not bespoke illustrations for 81 stories. Missing or blocked browser storage is handled in code but was not simulated in the visual checks. The preview is an isolated Pages subdirectory and can be removed by a later production publish. A preview is not a production publication receipt. News quality and source coverage are outside this visual change; the retained edition's existing source-audit limits still apply.
