# README media

The 20-second reader tour was made with the [Brag skill](https://github.com/latent-spaces/brag) and [Hyperframes](https://github.com/heygen-com/hyperframes). It uses actual captures of the public reader showing the 26 October 2026 edition. The captures are a recorded example; headlines and counts are not live. The video combines those captures with animated titles, music and two interface clicks. There is no voiceover.

- `reader-tour.mp4`: 1920 × 1080, 30 fps, with sound.
- `reader-tour.gif`: smaller, silent looping preview for GitHub's README.
- `reader-tour-poster.jpg`: a settled product frame, also baked into the MP4's first frame.
- `readme-banner.png`: AI-generated coastal illustration for the README. The reader's existing banner is unchanged.
